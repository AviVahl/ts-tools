# TypeScript Tools for Node.js

Several packages to assist [TypeScript](https://www.typescriptlang.org/) developers working with [Node.js](https://nodejs.org/en/).

## Packages

- **[@ts-tools/node-hooks](./packages/node-hooks)** - TypeScript support for Node.js. Exposes node hooks, allowing execution of `.ts`/`.tsx` files directly from source.
